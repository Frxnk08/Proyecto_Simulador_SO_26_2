# Evidencias de la Parte C

Esta carpeta contiene únicamente salidas generadas por ejecuciones reales.

- `votacion_windows.txt`: ejecución auténtica de polling en Windows.
- `sigalrm_linux.txt`: se añadirá después de ejecutar `interrupciones.py` en
  Linux u otro POSIX compatible.

El equipo utilizado para el desarrollo no tiene WSL instalado. Por esa razón no
se incluye una salida ficticia de SIGALRM. Cuando se genere la evidencia Linux,
cada ejecución mostrará avisos observados, trabajo útil y confirmación de que el
temporizador fue desactivado.
